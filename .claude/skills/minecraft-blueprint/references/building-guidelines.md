# 建築のコツ

Blueprint を「見栄えのする建物」にするための指針。仕様ではなく判断の目安。

## 設計の進め方

1. **寸法を決める**: 幅・奥行き・高さと階数。1 階の天井高は 4〜5 ブロック（床から天井まで 3〜4 の空間）。人が通る通路は幅 2 以上、ドアは高さ 2。
2. **座標を決める**: `origin` を入口の足元や中心の地面にすると貼り付けやすい。塔や左右対称の建物は中心を `x = 0, z = 0` に置くと `mirror` / `circle` が書きやすい。
3. **大きい順に書く**: 土台 → 外壁・床 → 屋根 → 開口部（窓・ドア）→ 装飾。後の Operation が前を上書きするので、くり抜きや窓は壁の後に書く。
4. **`size` を宣言する**: 想定サイズを `size` に書いておくと、はみ出しを validate が検出する。
5. **`comment` を付ける**: Operation ごとに何を作っているか書く。修正依頼のときに対象を見つけやすい。

## 質感（Palette）

- 石壁は `stone_bricks` を主にして `mossy_stone_bricks` / `cracked_stone_bricks` を 10〜30% 混ぜる。
- 木の壁は `oak_planks` に `spruce_planks` を少量、屋根は `dark_oak_stairs` など濃い色。
- 地面・土台は `cobblestone` + `mossy_cobblestone` + `andesite`。
- Palette は壁・床・屋根で分ける。同じ Palette を全面に使うとのっぺりする。
- 1 種類でよい部分（ドア、ガラス、装飾）は `block` を直接指定する。

## 構造

- **部屋**: 1 階分は `room` で作る（床・壁・天井・四隅の柱・ドア・窓を 1 つで指定でき、床とドアの高さの取り違えが起きない）。`from.y` が床の層、ドア下段は自動で `from.y + 1`。屋根は `roof` を `room` の `to.y` に重ねる。
- **外壁**: `wall` で外周を作り、角に `*_log`（`wall` で `from == to`）を立てると引き締まる。厚さ 1 で十分。大きな建物は `thickness: 2`。
- **床と天井**: `floor` を階ごとに置く。吹き抜けは後から `fill` で `air`。1 階の床は土台・地面と同じ高さ（入口のドア下段の 1 つ下の y）に置く。床をドアと同じ y に置くと室内が 1 段高くなる。
- **屋根**: `roof` を使う（`from` / `to` は軒の高さの壁の外周、`gable` に妻壁のブロック）。手で作る場合は階段ブロックを 1 段ずつずらして `repeat` し `mirror` で反対側を作る。斜面の階段は「登る方向」（建物の内側）を `facing` にする。屋根は壁より 1 ブロック張り出させる。
- **塔**: `tower` で外壁・各階の床・螺旋階段・胸壁・窓・入口をまとめて作る（屋上は自動で外壁より半径 +1 に張り出す）。屋根は屋上の高さ（`position.y + height + 1`）に `sphere` / `cylinder` / `roof` を載せる。手で作るなら `cylinder`（hollow）の外壁と `repeat` で `circle`（solid）の床。
- **窓**: 壁の後に `window`（接続プロパティは自動）。`repeat` で等間隔に、`mirror` で反対側の壁にも。地面から 2 ブロック目以上に置く。
- **入口**: 壁の後に `doorway`（`door` 指定でドア付き）。ドア下段の y は床の 1 つ上。土台が地面と面一なら踏み段は不要。
- **アーチ**: 門やアーチ窓は `doorway` / `window` の `arch`（`style` は中世なら `round`、教会なら `pointed`）。縁は必ず `trim` に縁と同じ素材の階段（`stone_bricks` なら `stone_brick_stairs`）を指定し、幅 5 以上なら `thickness: 2` にして外側も階段で滑らかにする（全部通常ブロックの縁は角ばって不自然）。開口はアーチの分だけ高くなるので、壁の高さに収まるか確認する（幅 3 の `round` で +1、`pointed` で +2）。
- **道・庭・門**: 建物どうしは `path` でつなぐ（幅 3、`edge` に縁石、`lights` で街灯）。畑や花壇は `garden`、城壁の入口は `gate`。地形が変わる場所は `fill` で段を作ってから道を通す。
- **橋**: `bridge` の `from` / `to` は両岸の地面と同じ y（路面の層）。幅は欄干込みで 5 以上にすると通路が 3 残る。太鼓橋は `stairs` を指定する（省略すると 1 ブロックの段差になりジャンプが要る）。
- **対称**: `mirror` の `at` は中心座標。幅が偶数なら `.5`（例: x が 0〜9 なら `at: 4.5`）。

## 通行できる空間（プレイヤーの寸法）

プレイヤーは幅 1 × 高さ 2 ブロック。通れない建物にしないための最低条件。

- **通路・出入口**: 空気が縦 2 ブロック以上。ドアの上にアーチ（逆さ階段など）を置くならドア上段のさらに 1 つ上（`y = ドア下段 + 2`）以上。
- **各階の高さ**: 床の上面から次の床の下面まで空気 3 ブロック以上（床の y 間隔は 4 以上）。
- **室内階段**: `stairs`（直進）か `spiral_stairs` を使う。どちらも各段の上の空気と上階への到着口を自動で確保する。手で作る場合は 1 段ごとに「1 上がって 1 進む」、各段の真上に空気 2 ブロック（できれば 3）を必ず確保する。
  - 段は `*_stairs[facing=<登る方向>]`（高い側が登る方向）、または通常ブロック。
  - 上階の床には階段の到着位置に開口（`fill` で `air`）を空ける。開口は「最後の 2〜3 段の真上」を含む長さにする。
  - 段数 = 上がる高さ。階段の水平方向の長さも同じだけ必要なので、建物の奥行きに収まるか先に確認する。狭い場合は折り返し階段（途中に踊り場 1 マス）にする。

```json
{
  "type": "repeat",
  "count": 4,
  "offset": [0, 1, 1],
  "comment": "南へ登る 4 段の階段。各段の上 2 ブロックを空ける",
  "operations": [
    { "type": "set", "position": [2, 1, 1], "block": "oak_stairs[facing=south]" },
    { "type": "fill", "from": [2, 2, 1], "to": [2, 3, 1], "block": "air" }
  ]
}
```

（この後、上階の床 `y = 5` の `[2, 5, 4]`〜`[2, 5, 6]` を `air` にして到着口を空ける）

- **はしご**: 縦に `ladder[facing=<壁と反対>]` を並べる。上端は上階の床の開口まで届かせる。
- **屋根裏・塔の上階**: 行けるようにするなら階段かはしごと開口を必ず作る。装飾だけなら不要。

## 向きと接続

- 階段の `facing` は「高い側」の方向。北側の壁の上に置く屋根の斜面は `facing=south`。
- `mirror` / `rotate` は `facing` / `axis` / 接続プロパティ / `half` / `type` を自動で変換し、`mirror` は階段の `shape` とドアの `hinge` の左右も入れ替える。看板・旗の `rotation` は変換されない。
- ガラス板・鉄格子・フェンス・壁ブロックは接続プロパティ（`north` / `south` / `east` / `west`）を明示する。X 方向に並ぶ窓は `east=true,west=true`、Z 方向は `north=true,south=true`。
- 原木の `axis` は伸びる方向。横に渡す梁は `axis=x` または `axis=z`。

## 支持が必要なブロック

支持のないブロックは貼り付け時のブロック更新で落ちて消える。下表の代表的なブロックは `validate` / `build` が `WARNING` で検出するが、それ以外は検証されないので置く前に支持先を確認する。

| ブロック | 条件 |
|---|---|
| 吊りランタン `lantern[hanging=true]`、鎖 `chain` | 真上が完全ブロック。ハーフブロック・階段の下には吊れない |
| 床置きランタン `lantern`、松明 `torch`、カーペット、草花・キノコ、レッドストーン、感圧板 | 真下の上面が完全な面。上付きハーフ（`type=top`）や逆さ階段（`half=top`）の上は可、下付きハーフ（`type=bottom`）の上は不可 |
| 壁松明 `wall_torch`、壁看板、ボタン、レバー、はしご `ladder`、つる、額縁 | 取り付け先が完全ブロック。`facing` は壁から離れる方向（北の壁に付けるなら `facing=south`） |
| ドア | 2 段（`half=lower` / `upper`）を同じ `facing` / `hinge` で置く。下段の下は完全ブロック |
| ベッド | 2 マス（`part=foot` / `head`）を同じ `facing` で置く |
| 農作物・苗木 | 耕地・土の上のみ |
| 水・溶岩 | 流れて広がるので囲いの中にだけ置く |

迷ったら装飾を完全ブロック（原木・レンガ・石）に付ける。ハーフブロック・階段・フェンス・ガラス板には付けない。

## 大きさの目安

| 建物 | 目安 |
|---|---|
| 小さな家 | 9〜13 × 高さ 8〜12 × 9〜13 |
| 塔 | 直径 9〜15、高さ 20〜40。4〜6 ブロックごとに床 |
| 城壁 | 厚さ 2〜3、高さ 8〜12、上に幅 1 の歩廊と胸壁 |
| 部屋 | 内寸 5×5 以上、天井高 3〜4 |

`mcblueprint build` が表示する `Bounds` と `Blocks` で、想定サイズと比べて確認する。
