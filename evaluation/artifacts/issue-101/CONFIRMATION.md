両入力とも validate → strict build 成功。生成範囲は X -3..9 / Y 0..12 / Z -3..10。入口ドア下段 `[3,1,0]`、一階到着足元 `[3,1,1]`、二階到着足元 `[1,5,6]`。二階床Y=4、最上階天井Y=8、屋根最上部Y=12。

元ブロック状態は全738セル（明示air込み）で一致し、#100 commit `2e10ede67ddd9523214bebed372c742c36938911` の外部previewで取得した7視点PNGも一致した。全セル一致・PNG一致はこの固定fixtureの自動検証であり、人間の同等品質やモデルの消費削減の証明ではない。入力サイズは685対1968 bytes。総トークンは未取得で、全試行評価は#97の確定記録方式に従って追加する。

AIによる画像確認では切妻の勾配/棟、各階窓、北側入口、階段側の上階開口と到着床を確認した。人間による外観/内部採点、実機配置・撮影・歩行は未実施。

## 実機担当への確認手順

ユーザーが許可した新規確認用ワールド（Java 1.21.11）だけで行う。実装担当はMinecraftの起動・配置を行っていない。

1. `building.schem` / `handwritten.schem` を読み込み、互いに離した貼り付け基準点へ配置する。両方の基準点、World識別子、座標、Minecraft版、mod/WorldEdit版を記録する。Blueprintのoriginは `[0,0,0]`、地面の床blockYも0なので、基準点のYが地面block層になる。
2. 北側から入口を視認し、ドアを開けて一階へ入る。歩行はteleport/flyで代替せず、通常歩行で確認する。
3. 室内を西へ寄り、ローカル `[1,1,1]` から南へ階段へ進む。階段を登り、二階の `[1,5,6]` へ到着する。頭の衝突、天井・上階床の塞がり、着地床欠落がないか確認する。逆方向に降りて入口から出られるかも確認する。
4. 各階の東・南窓、二階北窓から外を見られるか確認する。西の壁に窓は作らない固定仕様。
5. 外観isometric相当、北立面、東立面、上面、一階内部、二階内部、階段途中と到着口を撮影する。視点座標/向き、FOV、描画距離、リソースパックを記録する。
6. 同じ手順をhandwritten側でも行い、各variantについて結果と根拠画像を記録する。未実施/失敗を成功に置き換えない。
